## What this is

Projectotron undistorts sewing patterns projected onto fabric using a consumer projector and phone camera. Two devices collaborate: the projector goes fullscreen, publishes display resolution and tag-grid layout, and shows a QR join link; the phone scans the QR, detects AprilTags, computes a homography using the synced layout, and relays calibration via WebRTC (Trystero). The projector then pre-warps the pattern image before projecting so the result lands undistorted on the fabric plane.

See `CONTEXT-MAP.md` for product overview and usage flow.

## Architecture

**Stack:** SvelteKit 2 + Svelte 5 runes, Tailwind CSS 4, TypeScript 6 (strict), Vite 8.  
**Deployment:** Static site via `adapter-static` → GitHub Pages (`BASE_PATH` env var for project-site prefix).

### Key data flow

```
Phone camera
  → AprilTag WASM detection (static/apriltag WASM, accessed via window.AprilTagWasm)
  → DLT homography (src/lib/calibration/homography.ts)
  → CalibrationData via Trystero WebRTC sync (src/lib/sync/room.ts)
  → session state (src/lib/session.svelte.ts)

Projector
  → pre-warp canvas (src/lib/projection/warp.ts)
  → corrected image displayed fullscreen
```

### Session state (`src/lib/session.svelte.ts`)

Central Svelte 5 `$state` store. Holds `SessionRole` (Projector | Phone), calibration data, fine-tune settings, and Trystero room handles. All cross-device sync goes through here.

### Routes

| Route | Purpose |
|-------|---------|
| `/` | Calibration home — projector shows AprilTag grid + QR code for phone to scan |
| `/camera` | Phone view — live camera feed with tag detection overlay |
| `/reproject` | Projector reprojection — upload PDF/image, fine-tune rect, project undistorted |

### Calibration subsystem (`src/lib/calibration/`)

- `detect.ts` — wraps AprilTag WASM calls
- `homography.ts` — in-house DLT 4-point+ solver
- `solve.ts` — orchestrates detection → homography → `CalibrationData`
- `gutters.ts` — border/gutter adjustment for tag layout
- `pattern.ts` — generates the tag grid SVG/canvas

### Projection subsystem (`src/lib/projection/`)

- `warp.ts` — inverse-maps projector pixel space → source image (pre-warp)
- `fineTune.ts` — reference rectangle scaling and zoom
- `corners.ts` — quad geometry helpers

### Sync (`src/lib/sync/room.ts`)

Trystero over Nostr + WebRTC. JSON export/import is the offline fallback. The phone's session join URL is generated by `src/lib/joinUrl.ts` and shown as a QR code.

## Coding rules

- **Never** `import { base } from '$app/paths'`. Use `resolve(...)` instead (path resolution is handled via a project utility, not SvelteKit's base helper).
- Svelte 5 runes everywhere — `$state`, `$derived`, `$effect`. No legacy Svelte store syntax.
- Prefer TypeScript for new logic in `src/lib/**/*.ts`. Svelte components stay `.svelte` with `<script lang="ts">`.
- Formatting: tabs, single quotes, 100-char line width, no trailing commas (enforced by Prettier).
- Vitest is configured with `requireAssertions: true` — every test must call at least one `expect`.
- The AprilTag WASM is loaded as a side-effect global (`window.AprilTagWasm`); the type shim lives in `src/app.d.ts`.
